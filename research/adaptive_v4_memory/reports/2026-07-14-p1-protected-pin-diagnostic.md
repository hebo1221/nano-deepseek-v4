# P1 protected-pin causal diagnostic

Date: 2026-07-14  
Decision: **the pilot's 1x recovery is a protected-pin effect, not a quota-calibration effect**

The exact 20 `instruction-persistence` conversations from the S55 held-out
pilot were deterministically regenerated. A single new
`calibrated-hierarchical-no-pins-1x` arm was run against the already frozen
fixed-1x and pinned hierarchical-1x records.

| Context | Fixed 1x | Hierarchical no pins | Hierarchical with pins | Queries |

| **Total** | **44** | **44** | **57** | **80** |

No-pins predictions were bit-for-bit identical to fixed-1x predictions on all
80 queries. Enabling the pin recovered 13 queries and regressed none, with all
recoveries at context 256 or longer. Because 1x uses the same uniform layer
quota as fixed, the earlier +2.32 pp pooled pilot difference must be attributed
to protected instruction retention rather than calibrated layer allocation.

This is a clean causal mechanism check on one checkpoint, not a multi-seed
effect estimate. Protected pin is retained as an independent controller feature
and must be reported separately from quota calibration in the full matrix.
